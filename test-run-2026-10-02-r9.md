- **Bug 108** (KenshiFP loot): looting ignored what a body wears. Fixed (86cb3e6): search equipment sections of dead/downed bodies.
- **Bug 109** (Stobe combat): a fight never ended when the enemy walked off into a separate fight ~300 away; Malzin refused an order ("a bandit is breathing down our necks"). Fixed (3c7709d): local radius 150, far targets aren't evidence. Retested: combat_end 12 s after the bandit left.
- **Bug 110** (server/LLM): Malzin refused "loot everything from the Hungry Bandit's body" with "Already picked that one clean" — fresh bodies; her chat history about earlier bodies misled her. Not fixed (needs a server guard: loot orders run as goals, the goal decides).
- **Bug 111** (KenshiFP loot): full slots/pack reported as "found no weapons to take". Fixed (c15dec1).
- **Bug 112** (KenshiFP loot): weapons that go straight into her weapon slots counted 0 → "found no weapons". Fixed (2b62a1a).
- **Bug 113** (Stobe events): the player's own knockout/recovery/death were never events (Shay KO'd in a raid, no `[EVENT] knockout: Shay`). Fixed (4ca2d63).
- **Bug 98** (again, Stobe + server): see test 77. Fixed (56754be + StobeServer e51c2a4, fc08eed).
- **Bug 96** (again, server): see test 76. Fixed (StobeServer 072c3c5).
- **Bug 114** (KenshiFP loot): a big worn weapon (Staff) was dropped next to the body instead of looted. Fixed (81f6b90).

- **Bug 118** (KenshiFP): bridged actions (equip etc.) failed for a squad member >750 from Shay ("actor not found"). Fixed (fd1c317).
