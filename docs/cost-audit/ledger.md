## Method and assumptions

- Price table (USD per million tokens, from `tools/automation/prices.json`, same as `docs/MODEL_ROUTING.md`):

| Rate | Input | Output | Cache read | Cache write 5 min | Cache write 1 h |
|---|---|---|---|---|---|
| Haiku 5.5, prompt up to 100k | 0.1 | 0.5 | 0.01 | 0.125 | 0.2 |
| Haiku 5.5, prompt over 100k | 0.5 | 2.5 | 0.05 | 0.625 | 1.0 |
| Sonnet 5.5 | 2.0 | 10.0 | 0.1 | 2.5 | 4.0 |
| Opus 5.5 | 4.0 | 20.0 | 0.2 | 5.0 | 8.0 |

- Each message is priced at its own model. Cache writes: `cache_creation.ephemeral_5m_input_tokens` at the 5-minute rate, `ephemeral_1h_input_tokens` at the 1-hour rate; a record without the split is priced at 5 minutes.
- Haiku over-100k band: a Haiku message whose prompt (input + cache read + cache write) exceeds 100,000 tokens is billed at the over-100k rate for the whole prompt (the higher reading; the page does not say whether the band covers only the excess).
- Dedupe: Claude Code writes one JSON line per content block, all with the same `message.id` and `requestId`. Each message id counts once: across files the first occurrence wins; within a file the record with the largest `output_tokens` is kept. Stats: 101,404 message lines in total, 100,411 unique ids counted, 86,882 streamed duplicates inside files (3,427 with different usage), 993 cross-file duplicates skipped.
- Messages with a model string that has no rate in prices.json (counted at $0 in the totals; counted per file before cross-file dedupe, so the per-model table, after dedupe, is smaller): 1,172. By name: claude-fable-5-1 (with tokens) 1,128; <synthetic> (zero tokens) 44. Their tokens are in the per-model table under `unknown`. Their Haiku what-if IS priced (Haiku rates are known). A bound at Opus 5.5 rates is shown separately below; the real rate for these models is not in the table, so it is not added to the total.
- Day = local date of each message timestamp. Agent row day = its first message day; per-day table counts each message on its own day.
- Haiku what-if: the same token counts repriced at Haiku rates (same band rule). It does not change output length, so it is a price-only comparison. Shay's pilot (below) measured task-level cost with Haiku at high effort.
- Task type is a guess from the subagent description (`[case:x]` tag and keywords). Main sessions are "coordinator". Check the label column before acting on a row.
